MYCRAFT LAUNCHER 2.0 — WINDOWS

НАЙПРОСТІШИЙ ЗАПУСК:
1. Встанови Python 3.11 або 3.12 (64-bit): https://www.python.org/downloads/windows/
2. Під час встановлення Python познач Add Python to PATH.
3. Двічі натисни «Запустити_MyCraft.bat».
   Перший запуск завантажить потрібні бібліотеки, тому потрібен інтернет.

ЯК ЗРОБИТИ EXE:
1. Двічі натисни «Зібрати_EXE.bat» на Windows.
2. Після успішного завершення програма буде у dist\MyCraftLauncher\MyCraftLauncher.exe.

MICROSOFT:
Для входу через Microsoft потрібно налаштувати CLIENT_ID в config.py або змінну середовища MYCRAFT_CLIENT_ID.
Офлайн-режим доступний без цього, але не замінює ліцензійний Microsoft-акаунт для серверів, що перевіряють автентифікацію.

ВАЖЛИВО:
Цей архів містить готовий до запуску Python-проєкт і скрипт створення EXE. Сам Windows EXE не включено, оскільки його треба збирати у Windows-середовищі.
