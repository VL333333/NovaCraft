ЯК ЗРОБИТИ ПРОГРАМУ, ЯКУ МОЖЕ СКАЧАТИ БУДЬ-ХТО

ВАРІАНТ А (без Python, все робить GitHub безкоштовно):
1. Створи акаунт на github.com і новий репозиторій (Public).
2. Завантаж туди ВМІСТ цієї папки (разом з прихованою папкою .github).
3. Вкладка Actions -> "Build Windows installer" -> Run workflow.
4. Через ~5 хв внизу сторінки запуску в Artifacts буде MyCraftLauncher.zip з
   MyCraftLauncher_Setup.exe (інсталятор) і MyCraftLauncher_Portable.zip.
5. Для публічного посилання: створи тег v2.0 (Releases -> Draft new release -> tag v2.0).
   Файли автоматично з'являться в Releases — це і є посилання для скачування.

ВАРІАНТ Б (на своєму Windows-ПК):
1. Встанови Python 3.12 (з Add to PATH) і Inno Setup 6.
2. Двічі клікни Зібрати_EXE.bat.
3. Готовий інсталятор: installer_output\MyCraftLauncher_Setup.exe

ПЕРЕД ЦИМ ОБОВ'ЯЗКОВО:
- Впиши свій Azure CLIENT_ID у config.py (без нього вхід через Microsoft не працюватиме у інших людей).
  Client ID не є секретом, його можна вбудовувати. Client secret — ніколи.
- Windows SmartScreen показуватиме "невідомий видавець", бо EXE не підписаний
  сертифікатом. Це нормально: "Докладніше" -> "Все одно виконати".

ЯК ВИПУСТИТИ ОНОВЛЕННЯ (автооновлення)
1. Завантаж змінені файли на GitHub (Add file -> Upload files, Commit changes).
2. Releases -> Draft a new release -> новий тег, більший за попередній (v2.1, v2.2 ...) -> Publish release.
3. Зачекай зелену галочку в Actions (~3 хв). Номер версії підставляється з тегу сам.
4. Лаунчери в людей при наступному запуску запропонують оновитися.
Тег ОБОВ'ЯЗКОВО має бути більшим за попередній і починатися з v.
